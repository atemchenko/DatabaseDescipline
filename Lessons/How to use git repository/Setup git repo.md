## How to setup git and use repository

1. To install git goto https://git-scm.com/install choose your operation system and follow the instructions.
2. After installing git, select the folder where you want to deploy the local copy of the repository.
3. Open comand line and goto choosen directory.
4. Clone repository from github
>git clone https://github.com/atemchenko/DatabaseDescipline.git

After cloning the repository, you will see a DatatabaseDescipline folder with the repository data inside.

5. To get latest version of repository goto DataDescipline folder  execute command 

>git pull
